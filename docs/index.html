Sobre los datos: el anillo Oura no tiene GPS, así que distancia y ritmo son estimados y poco fiables para correr (por eso muchas salidas no muestran ritmo). La frecuencia cardíaca sí es precisa — es la base de este panel. Para ritmo/distancia reales, conectá una app con GPS.

Para actualizar con tus nuevas salidas, corré en la carpeta del proyecto:
python 2_fetch.py && python 3_analyze.py
y pedime que republique el dashboard.
